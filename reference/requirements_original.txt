# 6. ANNOTATION ENGINE

Giai đoạn đầu tập trung hoàn thiện **Object Detection — Bounding Box**.

Chức năng:
- Draw Bounding Box.
- Select Bounding Box.
- Move Bounding Box.
- Resize Bounding Box.
- Change Class.
- Delete Bounding Box.
- Duplicate Bounding Box.
- Undo / Redo.
- Zoom In / Zoom Out.
- Pan Image.
- Fit to Window.
- Hide / Show Annotations.

Yêu cầu:
- Một ảnh có nhiều đối tượng.
- Một ảnh có nhiều class.
- Các Bounding Box được phép chồng lên nhau.
- Có thể chọn box nằm bên dưới box khác.
- Không giới hạn số lượng box theo class.
- Không tạo Bounding Box có diện tích bằng 0.
- Không cho box nằm ngoài giới hạn ảnh.
- Không thay đổi ảnh gốc khi gán nhãn.

Phải tách chế độ thao tác rõ ràng:

**Draw Mode:** Vẽ Bounding Box mới.

**Select Mode:** Chọn đối tượng.

**Edit Mode:** Di chuyển, thay đổi kích thước Bounding Box.

**Pan Mode:** Di chuyển góc nhìn ảnh.

Sử dụng hệ tọa độ ảnh gốc làm nguồn dữ liệu chính, không dùng tọa độ cửa sổ làm dữ liệu annotation.

Các chức năng segmentation, polygon, keypoints hoặc oriented bounding box có thể bổ sung sau dưới dạng module độc lập. Không được hiển thị là đã hỗ trợ nếu chưa triển khai đầy đủ.

# 9. ANNOTATION FORMAT

## A. YOLO

Định dạng:

`class_id x_center y_center width height`

Yêu cầu:
- Tọa độ chuẩn hóa từ 0 đến 1.
- Một dòng là một đối tượng.
- Một file nhãn tương ứng một ảnh.
- Hỗ trợ đọc và ghi lại nhãn đã tồn tại.
- Bảo toàn Class ID.
- Không làm sai tọa độ khi resize/zoom.

## B. COCO JSON

Hỗ trợ import/export Object Detection COCO JSON.

Bao gồm:
- images.
- annotations.
- categories.
- Bounding Box theo tọa độ pixel.
- Category ID mapping phù hợp.

Phải xử lý đúng sự khác nhau giữa hệ Class ID của YOLO và Category ID của COCO.

## C. Pascal VOC

Có thể bổ sung Pascal VOC XML nếu triển khai đúng chuẩn.

Thiết kế Import/Export theo kiến trúc module để sau này có thể thêm các định dạng mới mà không cần sửa toàn bộ phần mềm.

Không được coi Bounding Box YOLO là segmentation mask. Không tạo dữ liệu polygon hoặc mask giả từ một bounding box.
